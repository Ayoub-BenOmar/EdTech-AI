# EdTech-AI
L'apprentissage traditionnel basé sur la lecture passive de documents (PDF) montre rapidement ses limites en termes de rétention et de compréhension. Les apprenants manquent souvent d'outils pour s'auto-évaluer efficacement ou pour obtenir un accompagnement pédagogique personnalisé sans recourir à un tuteur humain coûteux.
